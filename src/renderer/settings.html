🎵 Spotify Taskbar Player – Setup

You need a free Spotify Developer App to get API access.
Create one at developer.spotify.com/dashboard

Quick setup steps

  1. Go to the Spotify Developer Dashboard (link above)
  2. Click Create app
  3. Set app name to anything, e.g. Taskbar Player
  4. Set Redirect URI to http://localhost:8888/callback
  5. Tick Web API then save
  6. Copy the Client ID and Client Secret below
  7. Click Connect Spotify and log in in the browser
